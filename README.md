# Snap&Send

## What is Snap&Send?

Snap&Send is a Telegram bot for people who photograph slides, whiteboards,
and documents at events and never do anything with the photos afterward.
Send it one or more photos, and it extracts the visible text, preserving
whatever structure is actually on the page: headings, paragraphs, bullet
lists, tables, and flowcharts. It combines everything from a batch into one
set of notes and emails it to you shortly after your last photo.
